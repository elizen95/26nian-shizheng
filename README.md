## 这是什么

把 20 期时政讲练（约 53 万字）重新整理成一套可直接学习的资料：

- **按主题分模块**：不再是"按月摊开"，而是按 12 个考试模块归类
- **模块内时间倒序**：2026年10月 → 1月，最新的在最前（时政命题有近因偏重）
- **跨期去重**：同一政策/会议/事件在多个期次重复出现的，只保留信息最全的一版；
  前一期以预告形式提到、后一期正式详述的，只留详述版
- **重点加粗**：按「数字型 / 唯一性表述 / 时间节点 / 考眼词」四类规则标注

## 怎么用

### 直接读

打开 `教材/2026时政教材-分模块倒序版.pdf`。模块内从最新往前读，
第一遍只看加粗部分，第二遍再补细节。

### 用脚本检索

```bash
python 工具/shizheng.py list                    # 模块清单
python 工具/shizheng.py search -k 长征           # 关键词检索（带行号）
python 工具/shizheng.py month -m 10             # 10 月全部考点
python 工具/shizheng.py module -c 06 --limit 20 # 某模块前 20 条
python 工具/shizheng.py stats                   # 数据概况
```

```bash
python 工具/quiz.py list                        # 各模块题量
python 工具/quiz.py draw -c 03 -n 10            # 从模块3抽10题（不含答案）
python 工具/quiz.py draw -c 03 -n 10 --with-answer
python 工具/quiz.py paper -n 30 --seed 2026     # 跨模块组卷
```

> 脚本依赖 `数据/` 下的 JSON。若单独移植，保持目录相对位置不变。

### 作为 AI Skill

`SKILL.md` 是一个可用的 Agent Skill 定义，包含触发词、场景路由、
7 条工作流与答题纪律。放进 skills 目录即可让 AI 助手按本库作答。

## 重点标注规则

加粗不是随手标的，按四类生成：

| 类型 | 例子 |
|---|---|
| 数字型 | `60%`、`14亿吨`、`97.2万件` |
| 唯一性表述 | `我国首个`、`全球最大`、`首次`、`连续17年` |
| 时间节点 | `到2030年`、`2026年1月1日起施行` |
| 考眼词 | `根本保证`、`关键时期`、`战略基点` |

泛词（"高质量发展""中国式现代化"）**刻意不标**——出现频率过高，标了等于没标。

> 原始 PDF/DOCX 自带的加粗在格式转换时已被工具抹掉（20 个源文件中仅 1 个保留了
> 53 段真实加粗）。因此本库的加粗是**按上述规则重建**的，不是原书原样。
