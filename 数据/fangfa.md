# 时政备考方法与命题规律

## 一、时政题的四种命题方式

| 类型 | 长什么样 | 怎么防 |
|---|---|---|
| **数字型** | "突破 ___ 亿吨""占比达 ___%" | 数字必须和指标名称一起记，只背数字必错 |
| **名称型** | "首个/首次/最大 ___ 是（ ）" | 记"名称—成就—地点"三元组 |
| **并列型** | "下列属于/不属于 ___ 的是（ ）" | 记框架层级（几大板块、几个坚持） |
| **时点型** | "自 ___ 起施行""___ 周年" | 时间轴串记，按月份倒序过一遍 |

## 二、时政命题四大坑

1. **指标错配**：把 A 指标的数值安到 B 指标头上。
   例：宁波舟山港"货物吞吐量"14 亿吨全球第一，但"集装箱吞吐量"是全球第三。
2. **张冠李戴**：把甲会议的表述安到乙会议上。
   例："三大倡议"（全球发展/安全/文明）与"全球治理倡议"是不同时期提出的。
3. **数量偷换**：把"几个坚持"的条数改掉，或把其中一条替换成近义但错误的表述。
4. **级别混淆**：预警分级、应急响应级别的"一级最高"与"一级最低"方向反了。

## 三、三遍复习法（适配本库）

### 第一遍：通读（按模块，约 3～5 天）
- 顺序建议：03 → 01 → 02 → 04 → 05 → 07 → 09 → 10 → 06 → 08 → 11 → 12
  - 先学**主干**（03 十五五规划、01 求是文章、02 党建），这是理解其他模块的背景
  - 06/08 条数多但多为"名称型"，放后面用碎片时间过
- 每读完一个模块，立刻做该模块 10 题（`quiz.py draw -c <码> -n 10`）
- **不要抄笔记**，只标"数字"和"首次/首个"

### 第二遍：刷题（按模块，约 2～3 天）
- 每模块全量做一遍（题量见下表），错题记下题号
- 错题只在同模块内复测，不跨模块
- 目标：单模块正确率 ≥ 80%

### 第三遍：错题复测（约 1 天）
- 只做错题，用 `quiz.py answer -c <码> <题号...>` 直接看解析
- 连续两遍全对才算过

## 六、跨年更新

时政是按月滚动的。2027 年新增材料时，按下面顺序加：
1. 解析新一期 docx，抽出条目（保留 `period` 标签）
2. 用 `search` 检查是否与库内已有条目重复，重复的只补新增信息
3. 追加到对应模块 md 的**最前面**（因为是最新）
4. 同步更新 `references/index.json` 与 `references/textbook.json`
5. 题库同理，追加到 `references/q<码>.md` 与 `a<码>.md` 末尾（题号顺延）

> 详细流程见 `references/weihu.md`。
